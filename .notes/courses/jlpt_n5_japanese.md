# Lesson 1 — Foundations: Writing Systems & Pronunciation

## Section 1: Hiragana — Vowels & K/S/T/N Rows

**Content:**
Japanese has three writing systems: hiragana (for native words and grammar), katakana (for loanwords and emphasis), and kanji (Chinese characters). Hiragana is the first system every learner must master — it is phonetic, with each character representing one syllable (mora).

TEACHING APPROACH — Use the following drill cycle for EACH row of kana. Do NOT move to the next row until the student can produce the current row from memory:

STEP 1 — INTRODUCE VOWELS (あ行):
Introduce all five vowels with pronunciation guides:
- あ (a) — as in "father"
- い (i) — as in "machine"
- う (u) — compressed lips, between English "oo" and "uh"
- え (e) — as in "pet"
- お (o) — as in "go" but without the glide

Open the sketchpad with text_bg showing all five vowels. Have the student write each one. Then CLOSE the sketchpad and quiz: "Write あ... now write え... now write う..." in RANDOM order, not sequential. Repeat until the student gets all five correct without hesitation.

STEP 2 — DRILL K-ROW (か行):
Introduce: か (ka), き (ki), く (ku), け (ke), こ (ko).
Open sketchpad with text_bg showing the K-row. Have the student write each one. Then quiz in random order: "Write こ... write き... write か..."
Then MIXED REVIEW: Quiz randomly from BOTH vowels AND K-row. "Write お... write か... write い... write く..." Use start_timer for a 60-second speed round — call out characters and have the student write as many as possible.

STEP 3 — DRILL S-ROW (さ行):
Introduce: さ (sa), し (shi — not "si"), す (su), せ (se), そ (so).
Note the irregular reading: し is "shi." Open sketchpad, practice writing, then random quiz on S-row alone. Then CUMULATIVE REVIEW: random quiz from vowels + K-row + S-row. Use start_timer for a 90-second speed round.

STEP 4 — DRILL T-ROW (た行):
Introduce: た (ta), ち (chi — not "ti"), つ (tsu — not "tu"), て (te), と (to).
Note irregular readings: ち is "chi" and つ is "tsu." Same pattern: write, quiz row, then cumulative random review of ALL characters learned so far (20 characters). Use start_timer for a 2-minute speed round.

STEP 5 — DRILL N-ROW (な行):
Introduce: な (na), に (ni), ぬ (nu), ね (ne), の (no).
Same pattern: write, quiz row, then FULL CUMULATIVE REVIEW of all 25 characters. Use start_timer for a 2-minute speed round covering all 25 characters in random order.

STEP 6 — WORD READING:
Now introduce vocabulary that uses ONLY the characters learned so far. Have the student READ each word aloud, then write it:
いぬ (dog), ねこ (cat), さかな (fish), たこ (octopus), くに (country), あき (autumn), いけ (pond), うた (song), あさ (morning), きた (north), した (below), つき (moon), そと (outside)
Quiz: Say a word in English, student writes it in hiragana. Then show hiragana, student reads aloud.

STEP 7 — FINAL RANDOMIZED RECALL:
Use start_timer for a 3-minute comprehensive round. Alternate between: calling out romaji and having the student write the kana, showing kana and having them read it, and saying English words for them to write in hiragana.

**Key Concepts:**
- Recognize and write the five vowels from memory in any order: あ (a), い (i), う (u), え (e), お (o)
- Recognize and write K-row from memory in any order: か, き, く, け, こ
- Recognize and write S-row from memory in any order: さ, し, す, せ, そ — noting し is "shi" not "si"
- Recognize and write T-row from memory in any order: た, ち, つ, て, と — noting ち is "chi" and つ is "tsu"
- Recognize and write N-row from memory in any order: な, に, ぬ, ね, の
- Read and write words using learned kana: いぬ (dog), ねこ (cat), さかな (fish), たこ (octopus), くに (country), あき (autumn), いけ (pond), うた (song), つき (moon), あさ (morning)

## Section 2: Hiragana — H/M/Y/R/W Rows & ん

**Content:**
This section completes the basic hiragana chart. The student already knows 25 characters (vowels, K, S, T, N rows). This section adds the remaining 21 characters for a total of 46.

TEACHING APPROACH — Same progressive drill cycle as Section 1. Build each row cumulatively, always reviewing previous rows.

STEP 1 — REVIEW PREVIOUS:
Before teaching new characters, do a quick warm-up. Use start_timer for a 2-minute speed round: call out 10-15 random characters from Section 1 (vowels, K, S, T, N rows) and have the student write them. If the student struggles with any, re-drill those before proceeding.

STEP 2 — DRILL H-ROW (は行):
Introduce: は (ha), ひ (hi), ふ (fu — lips not touching, between "hu" and "fu"), へ (he), ほ (ho).
Note: ふ is "fu" not "hu" — the lips come close but don't touch.
Open sketchpad with text_bg showing the H-row. Student writes each, then random quiz on H-row alone.
Important rule to mention: は is normally "ha" but is pronounced "wa" when used as the topic particle. へ is normally "he" but is pronounced "e" when used as the directional particle. Drill this: "How do you pronounce は in わたしは?" (wa) "How do you pronounce は in はな?" (ha)

STEP 3 — DRILL M-ROW (ま行):
Introduce: ま (ma), み (mi), む (mu), め (me), も (mo).
Write, quiz row, then cumulative review of H + M rows. Then include some Section 1 characters in the mix.

STEP 4 — DRILL Y-ROW (や行):
Introduce: や (ya), ゆ (yu), よ (yo) — only three characters.
Write, quiz, cumulative review.

STEP 5 — DRILL R-ROW (ら行):
Introduce: ら (ra), り (ri), る (ru), れ (re), ろ (ro).
Note: The Japanese "r" is an alveolar flap — tongue briefly taps the ridge behind the upper teeth. Between English "l," "r," and "d." Similar to the "t" in American English "butter."
Write, quiz row, cumulative review.

STEP 6 — DRILL W-ROW & ん:
Introduce: わ (wa), を (wo/o — used only as the object particle), ん (n — the only standalone consonant; pronunciation shifts: m before b/p, ng before k/g, n elsewhere).
Write, quiz, then FULL 46-CHARACTER CUMULATIVE REVIEW.

STEP 7 — FULL CHART SPEED ROUND:
Use start_timer for a 3-minute speed round. Call out characters from ALL rows in completely random order. The student writes each one. Track how many they get correct. Then do a REVERSE round: open sketchpad showing random hiragana characters, student reads them aloud.

STEP 8 — WORD READING WITH NEW CHARACTERS:
Introduce vocabulary using the newly learned characters (H, M, Y, R, W rows). Have the student READ each word, then write it:
はな (flower/nose), やま (mountain), みず (water), むら (village), よる (night), もり (forest), わたし (I/me), ほん (book), まる (circle), ひる (noon), ゆめ (dream), れい (zero/example), ほし (star), はる (spring), ふゆ (winter)
Quiz: English to hiragana writing, then hiragana to reading aloud. Mix in words from Section 1 for cumulative practice.

**Key Concepts:**
- Recognize and write H-row from memory in any order: は, ひ, ふ, へ, ほ — noting ふ is "fu" not "hu"
- Recognize and write M-row from memory: ま, み, む, め, も
- Recognize and write Y-row (3 chars) from memory: や, ゆ, よ
- Recognize and write R-row from memory: ら, り, る, れ, ろ
- Recognize and write W-row and ん from memory: わ, を, ん
- Know that は = "wa" as topic particle and へ = "e" as directional particle
- Read and write words using all 46 hiragana: はな (flower), やま (mountain), みず (water), わたし (I/me), ほん (book), ほし (star), ゆめ (dream), はる (spring), ふゆ (winter)

## Section 3: Dakuten, Handakuten & Combination Characters

**Content:**
This section builds on the 46 basic hiragana by adding voiced marks (dakuten), semi-voiced marks (handakuten), and combination characters. The student does NOT need to learn new shapes — only modifications to characters they already know.

TEACHING APPROACH — Progressive drill with cumulative review. Since these are modifications of known characters, focus on RECOGNITION SPEED and accurate reading.

STEP 1 — WARM-UP REVIEW:
Use start_timer for a 2-minute speed round on the 46 basic hiragana from Sections 1-2. Identify any weak characters and re-drill briefly.

STEP 2 — INTRODUCE DAKUTEN (゛) — Voiced sounds:
Explain: Adding ゛ to certain kana voices the consonant (like adding vibration to the throat).
Introduce one row at a time, drilling each before moving on:

Batch 1 — が行: か→が (ga), き→ぎ (gi), く→ぐ (gu), け→げ (ge), こ→ご (go)
Open sketchpad with text_bg showing か→が pairs. Student writes each が-row character. Then random quiz: "Write ぐ... write が... write げ..." Mix in some base か-row characters to ensure they distinguish voiced from unvoiced.

Batch 2 — ざ行: さ→ざ (za), し→じ (ji), す→ず (zu), せ→ぜ (ze), そ→ぞ (zo)
Same drill pattern. Then cumulative quiz mixing が-row and ざ-row.

Batch 3 — だ行: た→だ (da), ち→ぢ (ji), つ→づ (zu), て→で (de), と→ど (do)
Note: じ and ぢ are both "ji"; ず and づ are both "zu." In modern use, じ and ず are standard; ぢ and づ appear only in compounds (はなぢ — nosebleed, つづく — to continue).

Batch 4 — ば行: は→ば (ba), ひ→び (bi), ふ→ぶ (bu), へ→べ (be), ほ→ぼ (bo)

After all four dakuten rows: Use start_timer for a 2-minute speed round. Call out random dakuten characters — student writes them. Mix in some base (unvoiced) characters to test discrimination.

STEP 3 — INTRODUCE HANDAKUTEN (゜) — は-row only:
は→ぱ (pa), ひ→ぴ (pi), ふ→ぷ (pu), へ→ぺ (pe), ほ→ぽ (po)
Drill: Student must distinguish は/ば/ぱ, ひ/び/ぴ, etc. Open sketchpad and quiz: "Write ぱ... write ば... write は..." in random order. This three-way distinction is critical.

STEP 4 — INTRODUCE COMBINATION CHARACTERS (拗音 yōon):
Explain: A consonant kana + small や/ゆ/よ creates a single-mora combination sound.
Introduce the most common combinations first:
- しゃ (sha), しゅ (shu), しょ (sho)
- ちゃ (cha), ちゅ (chu), ちょ (cho)
- きゃ (kya), きゅ (kyu), きょ (kyo)
Open sketchpad with text_bg showing these. Student writes each. Then quiz in random order. Add remaining combinations:
- にゃ (nya), にゅ (nyu), にょ (nyo)
- ひゃ (hya), ひゅ (hyu), ひょ (hyo)
- みゃ (mya), みゅ (myu), みょ (myo)
- りゃ (rya), りゅ (ryu), りょ (ryo)
And dakuten/handakuten variants: ぎゃ, じゃ, びゃ, ぴゃ, etc.
Use start_timer for a 90-second speed round on combination characters.

STEP 5 — SPECIAL CHARACTERS:
Explain small っ (geminate consonant — a brief pause): がっこう (gakkou — school), きって (kitte — stamp), ざっし (zasshi — magazine).
Explain long vowels: add the same vowel (おかあさん — okaasan — mother) except long "o" which uses う (おとうさん — otousan — father).

STEP 6 — WORD READING AND WRITING DRILL:
Have the student read and write these words using dakuten, handakuten, combinations, and special characters. Quiz in BOTH directions (English→hiragana and hiragana→reading):
がっこう (school), ぎゅうにゅう (milk), しゃしん (photo), ちょっと (a little), じゃ (well then), びょういん (hospital), ぱんだ (panda), ざっし (magazine), でんわ (telephone), べんきょう (study), じてんしゃ (bicycle)
Use start_timer for a 2-minute word-writing sprint.

**Key Concepts:**
- Write and read all dakuten forms from memory: が/ざ/だ/ば series — distinguish from unvoiced bases
- Write and read handakuten forms: ぱ, ぴ, ぷ, ぺ, ぽ — distinguish は/ば/ぱ three-way contrast
- Write and read common combination characters: しゃ, ちゅ, きょ, にゃ, etc.
- Apply っ (small tsu) as a consonant doubler and long vowel rules
- Read and write words with modified kana: がっこう (school), ぎゅうにゅう (milk), しゃしん (photo), ちょっと (a little), びょういん (hospital), ざっし (magazine), べんきょう (study), じてんしゃ (bicycle)

## Section 4: Katakana

**Content:**
Katakana maps one-to-one with hiragana but is used for: loanwords (mainly from English), foreign names, onomatopoeia, and emphasis (like italics in English). Since the student already knows hiragana, katakana can be taught faster — the sounds are identical, only the shapes differ.

TEACHING APPROACH — Batch-and-drill with hiragana-katakana pairing. Teach rows in larger batches than hiragana since the readings are already known. Focus on SHAPE RECOGNITION and WRITING, plus confusable pair discrimination.

STEP 1 — INTRODUCE VOWELS + K + S ROWS (15 characters):
Show each katakana alongside its hiragana pair:
ア (a)=あ, イ (i)=い, ウ (u)=う, エ (e)=え, オ (o)=お
カ (ka)=か, キ (ki)=き, ク (ku)=く, ケ (ke)=け, コ (ko)=こ
サ (sa)=さ, シ (shi)=し, ス (su)=す, セ (se)=せ, ソ (so)=そ

Open sketchpad with text_bg showing the katakana paired with hiragana. Student writes each katakana. Then CLOSE reference and quiz randomly: "Write カ... write ス... write エ..." Use start_timer for a 90-second speed round on these 15 characters.

STEP 2 — ADD T + N + H ROWS (15 more, total 30):
タ (ta), チ (chi), ツ (tsu), テ (te), ト (to)
ナ (na), ニ (ni), ヌ (nu), ネ (ne), ノ (no)
ハ (ha), ヒ (hi), フ (fu), ヘ (he), ホ (ho)
Same pattern: show with hiragana pairs, write, quiz row, then cumulative quiz of all 30. Use start_timer for a 2-minute speed round.

STEP 3 — ADD M + Y + R + W + ン (remaining 16, total 46):
マ (ma), ミ (mi), ム (mu), メ (me), モ (mo)
ヤ (ya), ユ (yu), ヨ (yo)
ラ (ra), リ (ri), ル (ru), レ (re), ロ (ro)
ワ (wa), ヲ (wo), ン (n)
Write, quiz, then FULL 46-CHARACTER speed round. Use start_timer for 3 minutes.

STEP 4 — CONFUSABLE PAIRS DRILL:
These pairs trip up every learner. Drill each pair intensively with the sketchpad:
- シ (shi) vs ツ (tsu): シ has strokes going left-to-right horizontally; ツ has strokes going top-to-bottom. Open sketchpad showing both side by side. Have student write each 3 times, then random quiz: "Write シ... write ツ... write シ..." 10 times fast.
- ン (n) vs ソ (so): Same principle — ン strokes go left-to-right; ソ strokes go top-to-bottom. Drill same way.
- ノ (no) vs メ (me): メ has an extra stroke. Drill.
- Additional pairs: ワ (wa) vs ウ (u) vs フ (fu), ヌ (nu) vs ス (su)
Use start_timer for a 90-second "confusable pairs only" speed round.

STEP 5 — DAKUTEN, HANDAKUTEN & LONG VOWELS:
Dakuten and handakuten work the same as hiragana: ガ, ザ, ダ, バ, パ, etc.
Long vowels in katakana use ー (horizontal bar), NOT vowel doubling: コーヒー (koohii — coffee), ケーキ (keeki — cake).
Quiz: "Write コーヒー... write ケーキ..."

STEP 6 — LOANWORD READING AND WRITING DRILL:
This is the real test of katakana — reading common loanwords. Introduce each word, have the student read it aloud, then write it from dictation:
コーヒー (coffee), テレビ (TV), パソコン (personal computer), レストラン (restaurant), ホテル (hotel), タクシー (taxi), アメリカ (America), ビール (beer), パン (bread), ペン (pen), ノート (notebook), スマホ (smartphone), トイレ (toilet), エレベーター (elevator), スーパー (supermarket)

Then REVERSE drill: say the English word, student writes in katakana. Use start_timer for a 3-minute loanword writing sprint.

STEP 7 — MIXED HIRAGANA-KATAKANA READING:
Show words in either hiragana or katakana randomly. Student must read each correctly. This tests that they don't confuse the two systems:
さかな, コーヒー, がっこう, テレビ, わたし, ホテル, びょういん, パン, しゃしん, レストラン

**Key Concepts:**
- Write and read all 46 basic katakana from memory in random order
- Write and read dakuten/handakuten katakana: ガ, ザ, ダ, バ, パ series
- Accurately distinguish confusable pairs: シ/ツ, ン/ソ, ノ/メ, ワ/ウ/フ
- Use ー for long vowels in katakana (not vowel doubling)
- Read and write common loanwords: コーヒー (coffee), テレビ (TV), パソコン (PC), レストラン (restaurant), ホテル (hotel), タクシー (taxi), ビール (beer), パン (bread), ペン (pen), ノート (notebook), スマホ (smartphone), スーパー (supermarket)

## Section 5: Japanese Pronunciation & Phonetics

**Content:**
Japanese pronunciation follows consistent rules that differ significantly from English:

Mora timing: Japanese is mora-timed, not stress-timed. Each mora (kana character) gets equal duration. きょう (kyou — today) has two morae: きょ + う. English speakers tend to rush unstressed syllables — in Japanese every mora matters equally.

Vowel devoicing: The vowels い and う become voiceless (whispered or silent) between voiceless consonants (k, s, t, h, p) or at the end of utterances. Examples: すき (suki — like) sounds like "ski"; です (desu) sounds like "des"; ～ます (masu) sounds like "mas."

Pitch accent: Japanese uses pitch (high/low) rather than stress (loud/soft). Tokyo dialect patterns include:
- 平板 (heiban — flat): low-high-high-high (e.g., さくら)
- 頭高 (atamadaka — head-high): high-low-low (e.g., いのち)
- 中高 (nakadaka — middle-high): low-high-low (e.g., たまご)
- 尾高 (odaka — tail-high): low-high-high + drops on particle

At N5 level, awareness of pitch accent is sufficient — production perfection is not expected. Focus on even mora timing and not adding English stress patterns.

The "r" sound: Japanese ら行 is an alveolar lateral flap — the tongue briefly taps the ridge behind the upper teeth. It is between English "l," "r," and "d." Practice: らく (comfort), りんご (apple), るす (absence).

**Key Concepts:**
- Explain mora-timed rhythm and produce even-length morae
- Apply vowel devoicing rules: です → "des", すき → "ski", ～ます → "mas"
- Understand pitch accent categories at a basic level (heiban, atamadaka)
- Produce the Japanese flapped "r" sound correctly
- Vocabulary: さくら (cherry blossom), たまご (egg), りんご (apple), すき (like), きょう (today), せんせい (teacher), がくせい (student)

# Lesson 2 — Basic Grammar & Sentence Structure

## Section 1: The Copula です & Basic Sentences

**Content:**
TEACHING APPROACH — For all grammar sections: ALWAYS introduce and drill new vocabulary FIRST, before teaching the grammar pattern that uses those words. The student must know the words before seeing them in sentences.

STEP 1 — VOCABULARY FIRST:
Introduce these words one at a time. For each word: say it, have the student repeat it, then ask "What does [word] mean?" Cycle through all words, then do a rapid-fire quiz using start_timer for 60 seconds — say the English, student says the Japanese:
- わたし (I/me)
- あなた (you — mention this is used sparingly in Japanese; using someone's name is preferred)
- がくせい (student)
- せんせい (teacher)
- かいしゃいん (office worker)
- いしゃ (doctor)
- ともだち (friend)
- にほんじん (Japanese person)

Then reverse: say Japanese, student says English. Drill until quick recall.

STEP 2 — INTRODUCE THE PATTERN:
The most fundamental Japanese sentence pattern is: [X] は [Y] です。(X wa Y desu — X is Y.)

です (desu) is the polite copula — it roughly means "is/am/are." It has no conjugation for person or number. Japanese sentences are SOV (Subject-Object-Verb) — the verb (or copula) always goes at the end.

Model sentences (read each aloud, have student repeat, then have student produce similar ones):
わたしは がくせい です。— I am a student.
これは ほん です。— This is a book.
やまださんは せんせい です。— Mr. Yamada is a teacher.

Drill: Ask the student to make their own sentences: "Say 'I am a teacher'... say 'Yamada is a doctor'... say 'I am Japanese'..." Use start_timer for a 90-second sentence-building sprint.

STEP 3 — NEGATIVE FORM:
Negative: では ありません (de wa arimasen) or じゃ ありません (ja arimasen — more casual)
わたしは せんせい では ありません。— I am not a teacher.
Drill: "Say 'I am not a student'... say 'Tanaka is not a doctor'..."

STEP 4 — PAST & PAST NEGATIVE:
Past: でした (deshita) — きのうは にちようび でした。— Yesterday was Sunday.
Past negative: では ありませんでした (de wa arimasen deshita)
Drill: "Say 'Yesterday was Monday'... say 'It was not Sunday'..."

STEP 5 — HONORIFIC SUFFIXES:
Introduce: ～さん (general polite), ～せんせい (for teachers/doctors), ～くん (familiar, often for boys), ～ちゃん (endearing, often for children/close friends). Rule: Never use ～さん for yourself.
Drill: "How would you address your teacher? Your friend Tanaka? A young boy named Kenji?"

STEP 6 — COMPREHENSIVE DRILL:
Use start_timer for a 2-minute round. Mix all forms: give English sentences, student produces Japanese using positive, negative, past, and past negative です forms. Include honorific suffix usage.

**Key Concepts:**
- Construct [X]は[Y]です sentences correctly
- Form negative with じゃありません / ではありません
- Form past with でした and past negative with ではありませんでした
- Know SOV word order: verb/copula always at the end
- Use honorific suffixes appropriately: さん, せんせい, くん, ちゃん
- Vocabulary: わたし (I), あなた (you — use sparingly), がくせい (student), せんせい (teacher), かいしゃいん (office worker), いしゃ (doctor), ともだち (friend), にほんじん (Japanese person)

## Section 2: Particles は, が, を, も

**Content:**
TEACHING APPROACH — Vocab first, then grammar, then drill.
STEP 1 — VOCABULARY: Before explaining any grammar, introduce the vocabulary listed in Key Concepts. Say each word, have the student repeat, give the meaning. Then rapid-fire quiz with start_timer (60 seconds): say English, student says Japanese. Reverse: say Japanese, student says English. Do not proceed until the student can recall all new words.
STEP 2 — TEACH: Explain the grammar point using the content below. After each new pattern, immediately have the student produce 2-3 example sentences using it. Do not lecture for more than 2-3 sentences before requiring student production.
STEP 3 — DRILL: After teaching all patterns in this section, use start_timer for a 2-minute comprehensive drill. Mix all patterns from this section: give English sentences or prompts, student produces Japanese. Include vocabulary from this AND previous sections for cumulative review.

Particles are the backbone of Japanese grammar. They are postpositions — they come after the word they mark.

は (wa — topic marker): Marks what the sentence is about. Often translates as "as for X" or simply marks the subject in English.
わたしは にほんご を べんきょう します。— (As for me,) I study Japanese.

が (ga — subject/identifier marker): Identifies the subject, often with new information, existence verbs (ある/いる), or after question words.
だれが きましたか。— Who came?
ねこが います。— There is a cat.
わたしが たなかです。— I am Tanaka. (identifying oneself)

は vs が: This is one of the trickiest distinctions in Japanese.
- は sets the topic (known info): 「たなかさんは がくせいです」 — (Speaking of) Tanaka, he is a student.
- が identifies/specifies (new info): 「たなかさんが がくせいです」 — Tanaka (is the one who) is the student.
- After question words, always が: だれが、なにが、どこが
- With ある/いる (existence): が is standard

を (wo/o — direct object marker): Marks the thing being acted upon.
パンを たべます。— I eat bread.
にほんごを べんきょうします。— I study Japanese.
みずを のみます。— I drink water.

も (mo — "also/too"): Replaces は, が, or を to mean "also."
わたしも がくせいです。— I am also a student.
パンも たべます。— I also eat bread.

**Key Concepts:**
- Use は to mark the topic of a sentence
- Use が to identify subjects, especially with question words and existence verbs
- Use を to mark direct objects
- Use も to mean "also," replacing は/が/を
- Distinguish は vs が in context: topic (known) vs identifier (new)

に (ni) has several core uses:
1. Time: specific points in time (but NOT relative time words like きょう, あした)
   七じに おきます。— I wake up at 7 o'clock.
   月ようびに あいます。— I meet (someone) on Monday.
2. Location of existence (with ある/いる):
   つくえの うえに ほんが あります。— There is a book on the desk.
3. Destination/direction (interchangeable with へ):
   がっこうに いきます。— I go to school.
4. Indirect object (recipient):
   ともだちに てがみを かきます。— I write a letter to my friend.

で (de):
1. Location of action: Action happens AT this place.
   としょかんで べんきょうします。— I study at the library.
   レストランで たべます。— I eat at a restaurant.
2. Means/method:
   バスで いきます。— I go by bus.
   にほんごで はなします。— I speak in Japanese.
   はしで たべます。— I eat with chopsticks.

に vs で for location:
- に = where something EXISTS (static): へやに います — I am in the room
- で = where an ACTION happens: へやで べんきょうします — I study in the room

へ (e — directional particle): Indicates direction of movement. Interchangeable with に for destinations but emphasizes the direction/journey rather than the arrival point.
にほんへ いきます。— I go to(ward) Japan.

の (no — possessive/modifier): Connects nouns. The modifier comes first.
わたしの ほん — my book
にほんの たべもの — Japanese food
がっこうの せんせい — school teacher
Can chain: わたしの がっこうの せんせい — my school's teacher

- Use に for time points, existence location, destination, and indirect objects
- Use で for action location and means/method
- Distinguish に (existence) vs で (action) for location
- Use へ for direction of movement
- Use の to connect nouns (modifier + の + modified)

Japanese verbs are categorized into three groups. Knowing the group is essential for all conjugation:

Group 1 — 五段動詞 (Godan / U-verbs): The dictionary form ends in an う-column sound. These are the largest group.
Examples: かく (write), のむ (drink), はなす (speak), まつ (wait), しぬ (die), あそぶ (play), かう (buy), おわる (end)

Group 2 — 一段動詞 (Ichidan / Ru-verbs): The dictionary form ends in -いる or -える. Drop -る to get the stem.
Examples: たべる (eat), みる (see), おきる (get up), ねる (sleep), でる (go out), おしえる (teach)

Group 3 — Irregular verbs: Only two:
- する (suru — to do)
- くる (kuru — to come)

Warning — false friends that LOOK like Group 2 but are Group 1:
かえる (return), はいる (enter), しる (know), はしる (run), きる (cut). These conjugate as Group 1.

ます-form (polite present/future):
- Group 1: Change the final う-column sound to い-column + ます
  かく → かきます, のむ → のみます, はなす → はなします
- Group 2: Drop る, add ます
  たべる → たべます, みる → みます
- Group 3: する → します, くる → きます

**Key Concepts:**
- Identify verb groups: Group 1 (u-verbs), Group 2 (ru-verbs), Group 3 (irregular)
- Convert Group 1 verbs to ます-form by changing う→い column + ます
- Convert Group 2 verbs by dropping る and adding ます
- Know the two irregular verbs: する→します, くる→きます
- Recognize false Group 2 verbs: かえる, はいる, しる, はしる, きる
- Vocabulary: かく (write), のむ (drink), はなす (speak), まつ (wait), かう (buy), たべる (eat), みる (see), おきる (get up), ねる (sleep), する (do), くる (come)

Japanese distinguishes between transitive verbs (他動詞 — tadoushi, someone does the action TO something) and intransitive verbs (自動詞 — jidoushi, something happens on its own). Many come in pairs:

| Transitive (を)     | Intransitive (が)    | Meaning            |
|---------------------|----------------------|---------------------|
| あける (open sth)    | あく (sth opens)      | open               |
| しめる (close sth)   | しまる (sth closes)   | close              |
| つける (turn on sth) | つく (sth turns on)   | turn on            |
| けす (turn off sth)  | きえる (sth goes off) | turn off / vanish  |
| いれる (put in)      | はいる (enter)        | put in / enter     |
| だす (take out)      | でる (come out)       | take out / exit    |
| はじめる (start sth) | はじまる (sth starts) | start/begin        |
| おわらせる (end sth) | おわる (sth ends)     | end/finish         |

Usage:
- Transitive takes を: ドアを あけます。— I open the door.
- Intransitive takes が: ドアが あきます。— The door opens.

This distinction does not exist in English in the same way — "I open the door" and "the door opens" use the same English verb. In Japanese, they are different verbs entirely.

At N5 level, focus on recognizing the most common pairs and using the correct particle (を for transitive, が for intransitive).

**Key Concepts:**
- Distinguish transitive (他動詞, takes を) from intransitive (自動詞, takes が)
- Know core pairs: あける/あく, しめる/しまる, つける/つく, けす/きえる
- Know core pairs: いれる/はいる, だす/でる, はじめる/はじまる
- Use を with transitive and が with intransitive verbs

Japanese adjectives conjugate — they carry tense and polarity without needing です for meaning (though です is added for politeness in polite speech).

い-adjectives end in い in their dictionary form. They conjugate by replacing い:

|              | Plain         | Polite              |
|-------------|---------------|---------------------|
| Present +   | たかい         | たかいです            |
| Present -   | たかくない      | たかくないです / たかくありません |

- おおきいです — is big

たかい やま — a tall mountain
おいしい たべもの — delicious food
あたらしい くるま — a new car

EXCEPTION: いい (good) is irregular. It conjugates from よい:
よくない, よかった, よくなかった (NOT いくない, いかった)
But the attributive form is いい: いい てんき — good weather

**Key Concepts:**
- Conjugate い-adjectives: replace い with くない (neg), かった (past), くなかった (past neg)

The て-form is one of the most important verb forms in Japanese. It is used for requests, progressive tense, connecting actions, permission, prohibition, and more. Mastering て-form construction is essential.

Group 2 (Ru-verbs) — simple: drop る, add て
たべる → たべて, みる → みて, おきる → おきて, ねる → ねて

Group 3 (Irregular):
する → して, くる → きて

Group 1 (U-verbs) — the て-form changes depend on the final kana. This is often taught with the "て-form song" (to the tune of a nursery rhyme):

| Dictionary ending | て-form ending | Example                |
|-------------------|---------------|------------------------|
| う, つ, る        | って           | かう→かって, まつ→まって, かえる→かえって |
| む, ぶ, ぬ        | んで           | のむ→のんで, あそぶ→あそんで, しぬ→しんで |
| く                | いて           | かく→かいて, きく→きいて       |
| ぐ                | いで           | およぐ→およいで              |
| す                | して           | はなす→はなして              |

Major exception: いく → いって (NOT いいて)

Mnemonic for Group 1:
- う/つ/る → っ (double consonant): って
- む/ぶ/ぬ → ん (nasal): んで
- く → い: いて (exception: いく→いって)
- ぐ → い: いで
- す → し: して

Practice: Convert these to て-form:
よむ (read) → よんで, あるく (walk) → あるいて, のる (ride) → のって, けす (turn off) → けして

**Key Concepts:**
- Apply Group 2 て-form: drop る, add て
- Apply Group 3 て-form: する→して, くる→きて
- Apply all Group 1 て-form rules: って/んで/いて/いで/して patterns
- Know the exception: いく→いって
- Vocabulary: かう (buy)→かって, まつ (wait)→まって, のむ (drink)→のんで, あそぶ (play)→あそんで, かく (write)→かいて, およぐ (swim)→およいで, はなす (speak)→はなして

## Section 2: ～ています — Progressive & Resultant States

**Content:**
TEACHING APPROACH — Vocab first, then grammar, then drill.
STEP 1 — VOCABULARY: Before explaining any grammar, introduce the vocabulary listed in Key Concepts. Say each word, have the student repeat, give the meaning. STEP 3 — DRILL: After teaching all patterns in this section, use start_timer for a 2-minute comprehensive drill. Mix all patterns from this section: give English sentences or prompts, student produces Japanese. Include vocabulary from this AND previous sections for cumulative review.

て-form + います creates two meanings:

1. Ongoing action (progressive — "is doing"):
いま ごはんを たべています。— I am eating a meal right now.
あめが ふっています。— It is raining.
にほんごを べんきょうしています。— I am studying Japanese.
でんわで はなしています。— I am talking on the phone.

2. Resultant state (the result of a completed action persists):
けっこんしています。— I am married. (the marriage happened and the state continues)
しっています。— I know. (I came to know and still know)
すんでいます。— I live (in a place). (I moved there and still reside)
きています。— I am wearing. (I put it on and it's still on)

How to tell which meaning: Verbs describing instantaneous/change-of-state actions → resultant state. Verbs describing durative actions → progressive.

Negative: ～ていません
たべていません。— I am not eating. / I have not eaten.
けっこんしていません。— I am not married.

Special case: しっています (I know) vs しりません (I don't know)
The negative of しっています is しりません (NOT しっていません, which sounds unnatural).

**Key Concepts:**
- Form ～ています for ongoing actions: たべています (is eating)
- Form ～ています for resultant states: すんでいます (live/reside), けっこんしています (married)
- Use ～ていません for negatives
- Know the special pair: しっています (know) vs しりません (don't know)
- Vocabulary: あめ (rain), ふる (fall — rain/snow)→ふっています, すむ (live/reside)→すんでいます, けっこんする (marry)→けっこんしています, しる (know)→しっています, きる (wear)→きています, もつ (hold/have)→もっています

## Section 4: Connecting Actions with て-form

**Content:**
TEACHING APPROACH — Vocab first, then grammar, then drill.
STEP 1 — VOCABULARY: Before explaining any grammar, introduce the vocabulary listed in Key Concepts. Say each word, have the student repeat, give the meaning. The て-form connects sequential actions, like "and" or "then" in English:

あさ おきて、かおを あらって、あさごはんを たべます。
— In the morning, I wake up, wash my face, and eat breakfast.

The tense of the final verb determines the tense of the whole chain:
きのう としょかんに いって、べんきょうしました。
— Yesterday I went to the library and studied.

This is one of the most natural ways to describe sequences in Japanese. Using separate sentences for each action sounds choppy.

て-form can also express cause/reason (informally):
あたまが いたくて、がっこうを やすみました。
— My head hurt, so I was absent from school.
(い-adjective て-form: replace い with くて — いたい → いたくて)

Adjective て-forms:
- い-adjective: replace い with くて: おおきくて、きれいな いえ — a big and beautiful house
- な-adjective: add で: しずかで、べんりな まち — a quiet and convenient town

Noun + で: がくせいで、にほんじんです — I am a student and Japanese.

**Key Concepts:**
- Chain actions with て-form: おきて、たべて、いきます
- Final verb determines tense of the entire chain
- Form い-adjective て-form: replace い with くて (おおきい→おおきくて)
- Form な-adjective て-form: add で (しずか→しずかで)
- Use て-form for informal cause/reason
- Vocabulary: かお (face), あさごはん (breakfast), ひるごはん (lunch), ばんごはん (dinner/supper), あたま (head), いたい (painful/hurts), やすむ (rest/be absent), シャワーをあびる (take a shower), はをみがく (brush teeth)

The most commonly tested N5 grammar points and frequent mistakes:

Particle errors (most common mistake category):
- は vs が: Topic vs subject. After question words → が. With ある/いる → が. Contrast → は.
  Wrong: だれは きましたか。 Right: だれが きましたか。
- に vs で: Existence location → に. Action location → で.
  Wrong: としょかんに べんきょうします。 Right: としょかんで べんきょうします。
- に with time: Use に with specific times, NOT with relative words.
  Wrong: きょうに。 Right: きょう (no particle). Wrong: さんじ。 Right: さんじに。

Verb conjugation errors:
- Group 1 て-form: The most error-prone area. Drill: のむ→のんで (NOT のみて)
- ます-form negative: ～ません (NOT ～ないです in polite speech at this level)
- いく irregular て-form: いって (NOT いいて)

Adjective errors:
- いい → よくない, よかった (NOT いくない, いかった)
- きれい and きらい are な-adjectives (NOT い-adjectives)
  Wrong: きれくない。 Right: きれいじゃない。

Word order:
- Time expressions typically come early in the sentence
- Frequency adverbs come before the verb
  わたしは まいにち にほんごを べんきょうします。(natural order)

Common grammar patterns that appear on every N5 test:
～ましょう, ～ませんか (invitation), ～てください, ～てもいいですか, ～てはいけません, ～ています, ～たいです, ～ことができます, ～たことがあります, ～つもりです

**Key Concepts:**
- Avoid common particle errors: は/が confusion, に/で for location, に with time words
- Avoid verb conjugation errors: Group 1 て-form, いく→いって exception
- Avoid adjective errors: いい conjugation, きれい/きらい as な-adjectives
- Recognize all major N5 grammar patterns in test format
- Vocabulary: まちがい (mistake), ただしい (correct), えらぶ (choose/select), こたえる (answer), なおす (fix/correct), れんしゅう (practice)

N5 listening comprehension tests four skills:

1. Task-based comprehension (もんだい1):
A situation is described, then a question is asked. You must determine the correct action or answer.
Common tasks: identifying which item, choosing correct time/place, understanding instructions.
Strategy: Listen for the question word (なに、どこ、いつ、だれ) and focus on that information.

2. Key point comprehension (もんだい2):
A conversation is played. You must understand the main point or specific detail.
Common topics: making plans, asking directions, ordering food, shopping.
Strategy: Note down numbers, times, and key nouns while listening.

3. Utterance selection (もんだい3):
You hear a situation and must choose the most appropriate response.
Tests natural conversation ability: greetings, apologies, requests, offers.
Key phrases to know:
- いただきます (before eating), ごちそうさまでした (after eating)
- いってきます (leaving home), いってらっしゃい (response to someone leaving)
- ただいま (returning home), おかえりなさい (welcoming someone home)
- おはようございます (good morning), こんにちは (hello/good afternoon), こんばんは (good evening)
- さようなら (goodbye), おやすみなさい (good night)
- すみません (excuse me/sorry), ありがとうございます (thank you), どういたしまして (you're welcome)
- おねがいします (please — requesting), しつれいします (pardon me — entering/leaving)
- はじめまして (nice to meet you), どうぞよろしく (pleased to meet you)

4. Quick response (もんだい4):
Short exchanges — you hear a line and choose the best reply from three options.
Strategy: Understand the function (question? invitation? offer?) and pick the response that matches.

General listening tips:
- Preview answer choices during the pause before audio
- Don't try to understand every word — focus on key content words
- If you miss something, don't dwell — the next question has started

**Key Concepts:**
- Identify the four listening question types and apply targeted strategies for each
- Know set phrases: いただきます, ごちそうさまでした, いってきます, ただいま, はじめまして
- Know greetings for all times of day: おはようございます, こんにちは, こんばんは, おやすみなさい
- Listen for question words and key content words rather than trying to catch every word
- Vocabulary: あいさつ (greeting), しょうかい (introduction), ちゅうもん (order — food), おかいけい (bill/check), おすすめ (recommendation), わりびき (discount), レシート (receipt)

Below is a model N5-level dialogue covering multiple grammar points. Students should be able to understand every line:

A: すみません、この ちかくに ゆうびんきょくは ありますか。
(Excuse me, is there a post office near here?)

B: ゆうびんきょくですか。ええ、ありますよ。この みちを まっすぐ いって、ふたつめの しんごうを みぎに まがってください。
(Post office? Yes, there is. Go straight on this road, and turn right at the second traffic light.)

A: ふたつめの しんごうを みぎですね。えきの ちかくですか。
(Right at the second light, right? Is it near the station?)

B: いいえ、えきより てまえです。ひだりがわに コンビニが あって、その となりです。
(No, it's before the station. There's a convenience store on the left, and it's next to that.)

A: わかりました。あるいて どのくらい かかりますか。
(I understand. About how long does it take on foot?)

B: そうですね、ごふんぐらいですよ。
(Let's see, about 5 minutes.)

A: ありがとうございます。あ、ゆうびんきょくは なんじまでですか。
(Thank you. Oh, until what time is the post office open?)

B: ごご ごじまでだと おもいます。
(I think it's until 5 PM.)

A: じゃ、いそがないと。どうも ありがとうございました。
(Then I'd better hurry. Thank you very much.)

Self-assessment checklist — students should be able to:
- Read all hiragana and katakana fluently
- Recognize ~80 of the 103 N5 kanji with at least one reading
- Conjugate verbs in ます-form (all four tenses)
- Construct て-form for all three verb groups
- Use all basic particles correctly (は, が, を, に, で, へ, の, も, と, か)
- Form comparative and superlative sentences
- Express desire (たい, ほしい), ability (ことができる), experience (たことがある)
- Tell time, count with basic counters, describe daily routines
- Give and understand simple directions
- Hold a basic conversation about self-introduction, daily life, plans, and preferences

**Key Concepts:**
- Parse a multi-turn N5 dialogue and extract key information (destination, directions, distance, time)
- Self-assess readiness against the N5 skill checklist
- Identify personal weak areas for targeted review before the exam
- Vocabulary: わかる (understand), いそぐ (hurry), かかる (take — time/money), おもう (think), てまえ (before/this side of), ひだりがわ (left side), みぎがわ (right side)
