# JLPT N4 Conversation Practice Course

> **Target:** Conversational fluency at JLPT N4 level
> **Companion to:** JLPT N4 Complete Japanese Course (grammar, writing, kanji)
> **Focus:** Real-world conversational competency through scenario-based practice with natural register switching
> **Lessons:** 8 | **Sections:** 29

# Lesson 1 — Casual Conversations with Friends

## Section 1: Catching Up with a Friend

**Content:**
This section simulates running into a friend you have not seen for a while. The student practices casual register exclusively — plain form verbs, sentence-ending particles (よ, ね, な, さ), and natural casual fillers. The agent plays the role of a college friend who bumps into the student at a cafe.

Model Dialogue:
- Agent: あ、ひさしぶり！げんきだった？
- Student: うん、げんき。○○ちゃんは？さいきんどうしてた？
- Agent: じつは、しごとやめたんだ。
- Student: えー、まじで？いつやめたの？
- Agent: せんげつ。あたらしいしごとをさがしてるんだけど、なかなかみつからなくて。
- Student: そうなんだ。たいへんだね。どんなしごとがしたいの？
- Agent: できれば、にほんごをつかうしごとがいいなと思って。
- Student: あ、それならいいかいしゃを知ってるよ。あとでおしえるね。
- Agent: ほんとに？ありがとう！たすかる！
- Student: うん、きにしないで。あ、じかんある？ちょっとおちゃでもしない？
- Agent: いいね！いこういこう。

Roleplay Instructions:
The agent greets the student casually. After the initial exchange, the agent should share a piece of news (changed jobs, moved, started a hobby) and ask the student about their life. The agent should gently correct any polite form used where casual form is expected, e.g., if the student says しごとをやめました, the agent says "ともだちだから、やめたんだ のほうがしぜんだよ." The agent should use open_sketchpad to display casual sentence-ending particles (よ、ね、な、さ、の、んだ) with example sentences as a reference during the conversation. Use start_timer for a 60-second rapid-fire drill at the end: the agent gives polite sentences and the student converts them to casual form.

Timed Drill (60 seconds):
Agent says polite form → student converts to casual:
しごとをやめました → やめたんだ / やめた
あたらしいくるまをかいました → あたらしいくるまかったよ
あしたともだちにあいます → あしたともだちにあう
きのうえいがをみませんでした → きのうえいがみなかった
にほんごがじょうずになりました → にほんごうまくなった

**Key Concepts:**
- Use plain form naturally in casual conversation: やめた、さがしてる、みつからない、知ってる
- Employ casual fillers and reactions: まじで？、そうなんだ、たいへんだね、たすかる
- Use んだ/んです for explanation and emphasis: やめたんだ、さがしてるんだけど
- Sentence-ending particles for nuance: よ (informing), ね (agreement-seeking), な (self-reflection), の (question softener)
- Phrases: ひさしぶり (long time no see), さいきんどうしてた？ (what have you been up to?), じつは (actually), なかなか～ない (not easily), できれば (if possible), きにしないで (don't worry about it), ～でもしない？ (shall we do ~ or something?)

## Section 2: Making Plans — Negotiating Time and Place

**Content:**
The student practices negotiating plans with a friend over text message style back-and-forth. This covers conditional たら for concrete planning, giving alternatives, expressing preferences casually, and compromising. The agent plays a friend trying to arrange a weekend outing.

Model Dialogue:
- Agent: こんどのどようび、ひまだったらどっかいかない？
- Student: どようびはちょっと。。。にちようびだったらあいてるけど。
- Agent: にちようびかー。ごごからだったらだいじょうぶだよ。
- Student: じゃあ、にちようびのごごにしよう。なにする？
- Agent: えいがはどう？みたいのがあるんだけど。
- Student: えいがもいいけど、てんきがよかったらこうえんにいきたいな。
- Agent: あー、いいね。てんきよかったらピクニックして、わるかったらえいがにする？
- Student: さんせい！じゃあそうしよう。どこであつまる？
- Agent: えきのまえでいい？いちじぐらいに。
- Student: おっけー。いちじにえきまえね。たのしみ！
- Agent: うん、たのしみにしてる！じゃあまたれんらくするね。

Roleplay Instructions:
The agent proposes an outing and the student should negotiate timing, activity, and meeting place. The agent should sometimes disagree or suggest alternatives to force real negotiation. If the student just agrees to everything, the agent should deliberately create a scheduling conflict: "あ、やっぱりごぜんちゅうはよういがあって..." to make the student counter-propose. The agent uses show_slide to display a simple weekly calendar visual showing available/busy time slots. After the dialogue, use start_timer for a 45-second drill where the agent states a situation and the student must quickly propose a plan using たら.

Timed Drill (45 seconds):
Agent gives a condition → student makes a plan:
あめがふったら → (student: うちでえいがをみよう)
やすみがとれたら → (student: おんせんにいきたいな)
おかねがあったら → (student: あたらしいレストランにいこう)
ひまだったら → (student: いっしょにかいものしない？)

**Key Concepts:**
- Use たら conditional for concrete plans: ひまだったら、てんきがよかったら、わるかったら
- Propose and counter-propose: ～はどう？、～もいいけど、～にしよう、じゃあそうしよう
- Express soft disagreement: ちょっと。。。、～だったらだいじょうぶだけど
- Casual planning vocabulary: どっか (どこか casual), ひま (free/available), あいてる (open/free), さんせい (agreed), やっぱり (after all/on second thought)
- Phrases: こんどの～ (this coming ~), ～にしよう (let's make it ~), たのしみにしてる (looking forward to it), またれんらくするね (I'll message you again), どこであつまる？ (where shall we meet?), ～ぐらいに (around ~ time)

## Section 3: Gossiping and Sharing News — Hearsay Forms

**Content:**
This section practices indirect speech and hearsay — essential N4 grammar used constantly in casual conversation. The student learns to relay information heard from others using と言っていました, そうです (hearsay), らしい, and みたい. The agent plays a mutual friend sharing gossip.

Model Dialogue:
- Agent: ね、きいた？たなかくん、らいげつけっこんするらしいよ。
- Student: えー！だれときくの？
- Agent: さとうさんがいってたんだけど、どうきのひととつきあってたみたいで。
- Student: ぜんぜんしらなかった！たなかくん、けっこんなんてしないっていってたのに。
- Agent: ね。でもすごくしあわせそうだって。
- Student: へー、よかったね。けっこんしきはいつだって？
- Agent: しちがつだっていってた。でも、まだくわしいことはわからないらしい。
- Student: そっか。おいわい、なにがいいかな。
- Agent: さとうさんによると、りょこうにいきたいっていってたから、りょこうけんとかどう？
- Student: いいかも！みんなでまとめてかったらやすくなるんじゃない？

Roleplay Instructions:
The agent shares a piece of surprising news about a mutual acquaintance. The student should practice reacting naturally and asking follow-up questions using hearsay forms. The agent corrects if the student directly states facts they only heard secondhand — e.g., if the student says たなかくんはけっこんする, the agent prompts: "じぶんできいたの？きいただけなら、けっこんするらしいよ がいいよ." The agent should use open_sketchpad to display a reference chart showing the three hearsay forms side by side: ～そうです (heard that), ～らしい (apparently), ～みたい (seems like, casual), with example sentences. Use start_timer for a 60-second drill: the agent gives a direct statement and the student rephrases it using the specified hearsay form.

Timed Drill (60 seconds):
Direct → hearsay conversion (agent specifies which form):
たなかくんはけっこんする (らしい) → たなかくんはけっこんするらしい
あのレストランはおいしい (そうです) → あのレストランはおいしいそうです
あしたあめがふる (みたい) → あしたあめがふるみたい
やまださんはかいしゃをやめた (と言っていた) → やまださんはかいしゃをやめたと言っていた
しけんはむずかしくなかった (らしい) → しけんはむずかしくなかったらしい

**Key Concepts:**
- Distinguish hearsay そうです from appearance そうです: あめがふるそうです (I heard it'll rain) vs あめがふりそうです (it looks like it'll rain)
- Use らしい for information heard indirectly: けっこんするらしい (apparently getting married)
- Use みたい for casual hearsay/appearance: つきあってたみたい (seems they were dating)
- Quote with と言っていた: ～っていってた (casual quoting)
- Phrases: きいた？ (did you hear?), ぜんぜんしらなかった (had no idea), ～だって (I heard that ~, casual), ～によると (according to ~), ～っていってたのに (even though they said ~), よかったね (that's great), いいかも (that might be good), ～んじゃない？ (isn't it ~ / don't you think?)

## Section 4: Giving and Getting Advice

**Content:**
The student practices asking for and giving advice using ～たらどう？, ～たほうがいい, ～ないほうがいい, and responding to advice. The agent plays a friend the student consults about a problem. This section also introduces ～てみたら？ (why not try ~?) as a softer suggestion.

Model Dialogue:
- Agent: どうしたの？なんかげんきなさそうだけど。
- Student: じつは、さいきんねむれなくて。しごとのストレスがすごいんだ。
- Agent: それはたいへんだね。うんどうはしてる？
- Student: ぜんぜん。じかんがなくて。
- Agent: まいにちすこしでもあるいたほうがいいよ。わたしもまえはねむれなかったけど、うんどうをはじめてからよくなった。
- Student: そうなんだ。でもいそがしくて、うんどうするじかんがないんだよね。
- Agent: じゃあ、ねるまえにストレッチしてみたら？じゅっぷんぐらいでいいんだよ。
- Student: ストレッチかー。それならできるかも。
- Agent: あと、ねるまえにスマホはみないほうがいいよ。ブルーライトがよくないらしいから。
- Student: あー、それはわかってるんだけど、やめられなくて。
- Agent: まず、ストレッチからはじめてみたらどう？むりしないでね。
- Student: うん、ありがとう。やってみる。

Roleplay Instructions:
The student presents a problem (the agent can suggest one if the student cannot think of one: sleep trouble, difficulty studying, relationship issue, etc.). The agent gives advice using the target grammar patterns. Then roles reverse — the agent presents a problem and the student must give advice. The agent should push back on some advice to force the student to offer alternatives: "それはちょっとむずかしいな..." Use show_slide to display an "advice strength scale" from soft to strong: ～てみたら？ → ～たらどう？ → ～たほうがいい → ～なきゃ/～ないと. After the roleplay, run a 45-second start_timer drill where the agent describes a problem and the student gives quick advice.

Timed Drill (45 seconds):
Agent states problem → student gives advice:
ふとってきた → うんどうしたほうがいいよ / あまいものはたべないほうがいいよ
にほんごがうまくならない → まいにちすこしでもはなしたほうがいいよ
ともだちとけんかした → あやまったほうがいいよ / れんらくしてみたら？
あさおきられない → はやくねたほうがいいよ / めざましをふやしてみたら？

**Key Concepts:**
- Give strong advice with ～たほうがいい: あるいたほうがいい (you should walk)
- Give negative advice with ～ないほうがいい: みないほうがいいよ (you shouldn't look at it)
- Suggest gently with ～てみたら？: ストレッチしてみたら？ (why not try stretching?)
- Propose with ～たらどう？: はじめてみたらどう？ (how about starting?)
- Phrases: どうしたの？ (what's wrong?), げんきなさそう (you seem down), それはたいへんだね (that's tough), ～からよくなった (it got better since ~), ～んだけどやめられない (I know but I can't stop), むりしないでね (don't overdo it), やってみる (I'll try it), わかってるんだけど (I know, but...)

# Lesson 2 — Expressing Yourself

## Section 1: Sharing Opinions About Movies, Books, and Food

**Content:**
N4 students need to express opinions beyond "good" and "bad." This section builds the vocabulary and grammar for nuanced opinion-giving: ～と思う, ～んじゃないかな, ～気がする, and casual opinion softeners. The agent and student discuss recent movies, books, or restaurants.

Model Dialogue:
- Agent: きのうあたらしいえいがをみたんだけど、すごくよかったよ。
- Student: なんのえいが？
- Agent: にほんのアニメ。ストーリーがふくざつで、さいごはかなしかったけど、すごくかんどうした。
- Student: へー、おもしろそう。わたしもみてみたいな。
- Agent: うん、ぜったいみたほうがいいよ。○○さんはさいきんなにかみた？
- Student: せんしゅう、ともだちにすすめられてほんをよんだんだけど、しょうじきあんまりおもしろくなかったんだよね。
- Agent: そうなの？どんなほん？
- Student: ミステリーなんだけど、ながすぎるとおもう。さいしょはよかったけど、なかのほうがつまらなくなって。
- Agent: なるほどね。ながいほんはとちゅうでやめたくなることがあるよね。
- Student: うん。でも、さいごはいがいとよかったきがする。
- Agent: じゃあ、よんでよかったんじゃない？
- Student: まあ、そうかもしれないけど、ひとにはすすめないかな。

Roleplay Instructions:
The agent shares an opinion about something cultural (movie, book, show, restaurant) and asks the student's opinion on something they have experienced recently. The agent should ask follow-up questions: どこがよかった？なにがつまらなかった？どうしてそうおもう？ If the student only uses いい/わるい, the agent should model more specific vocabulary: かんどうした (was moved), つまらなかった (was boring), ふくざつ (complex), いがい (unexpected). Use open_sketchpad to display an "opinion expression chart" with strength levels: つまらない → あんまり → まあまあ → けっこういい → すごくいい → さいこう. After the discussion, run a 45-second start_timer drill: the agent names something and the student gives a quick opinion using と思う.

Timed Drill (45 seconds):
Agent names item → student gives opinion with と思う:
すし → すしはにほんでいちばんおいしいたべものだとおもう
でんしゃ → にほんのでんしゃはべんりだとおもう
カラオケ → カラオケはたのしいけど、はずかしいとおもう

**Key Concepts:**
- State opinions with ～と思う: ながすぎるとおもう (I think it's too long)
- Soften opinions with ～きがする: よかったきがする (I have a feeling it was good)
- Hedge with ～んじゃないかな: いいんじゃないかな (I think it might be good, maybe)
- Express impressions: かんどうした (was moved/touched), いがいと (surprisingly), しょうじき (honestly)
- Phrases: ～にすすめられて (was recommended by ~), おもしろそう (sounds interesting), あんまり～ない (not really ~), とちゅうで (in the middle/partway), ひとにはすすめない (wouldn't recommend to others), さいこう (the best), まあまあ (so-so), しょうじきいって (to be honest)

## Section 2: Agreeing and Disagreeing Politely

**Content:**
Japanese communication avoids direct confrontation. This section teaches the student how to agree enthusiastically, agree partially, and disagree without being rude. Key patterns include そうだね (agreement), たしかに (indeed), でも/けど for gentle pushback, and ちょっとちがうとおもう for polite disagreement. The agent and student debate everyday topics.

Model Dialogue:
- Agent: にほんごをべんきょうするなら、にほんにすむのがいちばんいいとおもわない？
- Student: うーん、たしかににほんにすんだらはやくじょうずになるとおもうけど、いちばんかどうかはわからないな。
- Agent: そう？でもまいにちにほんごをつかわないとなかなかじょうずにならないんじゃない？
- Student: それはそうだけど、いまはオンラインでもたくさんはなせるし、にほんにすまなくてもだいじょうぶだとおもう。
- Agent: なるほど、たしかにそういうかんがえかたもあるね。でもぶんかをたいけんするのもたいせつじゃない？
- Student: うん、それはわたしもそうおもう。りょこうならさんせいだけど、すむのはちょっとハードルがたかいんじゃないかな。
- Agent: まあ、ひとそれぞれだよね。
- Student: うん、じぶんにあったやりかたでがんばるのがいちばんだとおもう。
- Agent: そうだね、それはまちがいないね。

Roleplay Instructions:
The agent states a mildly controversial opinion (e.g., "Japanese is easy to learn," "Living abroad is better than staying in your country," "Children should study more"). The student must agree or disagree using appropriate softening strategies. The agent should intentionally take strong positions to force the student to practice disagreement. If the student agrees with everything, the agent should switch sides: "え、でもさっきは○○っていってたのに？" Use show_slide to display a polite disagreement spectrum: そうだね (full agree) → たしかに、でも... (partial) → うーん、ちょっとちがうとおもう (disagree) → それはちがうよ (strong disagree, use rarely). Run a 60-second start_timer drill: agent gives an opinion, student must agree or disagree with a reason.

Timed Drill (60 seconds):
Agent states opinion → student agrees or disagrees with reason:
にほんごはかんたんだ → うーん、かんたんじゃないとおもう。かんじがむずかしいし。
あさはやくおきたほうがいい → たしかに。あさはしずかでべんきょうしやすいし。
おかねがいちばんたいせつだ → それはちょっとちがうとおもう。けんこうのほうがたいせつだし。

**Key Concepts:**
- Agree fully: そうだね、わたしもそうおもう、まちがいないね、さんせい
- Agree partially: たしかに～けど、それはそうだけど、わかるけど
- Disagree gently: うーん、ちょっとちがうとおもう、～かどうかはわからない、それはどうかな
- Use し to list reasons: オンラインではなせるし、にほんにすまなくてもいいし
- Phrases: ～とおもわない？ (don't you think?), そういうかんがえかたもある (there's that way of thinking too), ひとそれぞれ (different for everyone), ハードルがたかい (the bar is high), じぶんにあった (suited to oneself), それはまちがいない (that's for sure)

## Section 3: Expressing Feelings and Emotions

**Content:**
Moving beyond basic うれしい/かなしい, this section teaches emotional vocabulary and the grammar to express how things make you feel: ～てうれしい, ～てかなしい, ～てくやしい, ～ておどろいた. Also covers ～くてたまらない (unbearably ~) and ～てしかたがない (can't help feeling ~). The agent creates emotionally charged scenarios through roleplay.

Model Dialogue:
- Agent: きょう、すごくいいことがあったんだ。きいてくれる？
- Student: もちろん！なにがあったの？
- Agent: ずっとほしかったしごとにうかったんだ！
- Student: わー、おめでとう！それはうれしいね！
- Agent: うん、うれしくてたまらないよ。がんばってきてよかったとおもう。
- Student: ほんとうにがんばってたもんね。わたしもうれしいよ。
- Agent: でもじつは、ちょっとふあんでもあるんだ。あたらしいところでうまくやれるかなって。
- Student: しんぱいするきもちもわかるけど、○○ちゃんならだいじょうぶだよ。
- Agent: ありがとう。そういってもらえてうれしい。あ、でもいまのしごとのひとたちとわかれるのはさびしくてしかたがないんだよね。
- Student: そうだよね。でも、あたらしいであいもあるし、さびしいけどたのしみだね。
- Agent: うん、まえむきにがんばる！

Roleplay Instructions:
The agent shares a life event that involves mixed emotions (got a new job but sad to leave, passed a test but exhausted, friend moved away). The student must respond empathetically and share their own emotional experiences. The agent should ask follow-up questions about how the student felt in similar situations: "○○さんも、そういうけいけんある？そのときどんなきもちだった？" Use open_sketchpad to display an emotion vocabulary map grouped by category: joy (うれしい、たのしい、しあわせ), sadness (かなしい、さびしい、くやしい), anxiety (ふあん、しんぱい、きんちょう), surprise (おどろいた、びっくりした), anger (くやしい、いらいらする、むかつく). Run a start_timer 45-second drill: agent describes a situation and the student names the emotion and makes a sentence.

Timed Drill (45 seconds):
Agent describes situation → student states emotion with sentence:
しけんにおちた → くやしい。すごくべんきょうしたのに、おちてくやしくてたまらない。
ともだちがとおくにひっこした → さびしい。あえなくなってさびしくてしかたがない。
プレゼントをもらった → うれしい。おもってなかったからすごくうれしかった。

**Key Concepts:**
- Express strong emotion with ～てたまらない: うれしくてたまらない (so happy I can't stand it)
- Express uncontrollable feeling with ～てしかたがない: さびしくてしかたがない (can't help feeling lonely)
- Combine emotion with reason: うかってうれしい (happy that I passed), わかれるのがさびしい (sad to part)
- Empathetic responses: そのきもちわかるよ、それはつらいね、よかったね
- Phrases: きいてくれる？ (will you listen?), がんばってきてよかった (glad I persevered), そういってもらえてうれしい (happy you said that), まえむきに (positively/looking forward), ふあんでもある (also anxious), うまくやれるかな (I wonder if I can do well)

## Section 4: Talking About Experiences — たことがある and ようになった

**Content:**
This section practices talking about life experiences with ～たことがある (have done ~) and describing changes over time with ～ようになった (came to be able to ~) and ～なくなった (stopped doing ~). These are essential for natural conversation about personal history and growth. The agent and student share travel stories and personal development.

Model Dialogue:
- Agent: ○○さんはがいこくにいったことある？
- Student: うん、タイにいったことがあるよ。にかいいったことがある。
- Agent: いいね！タイりょうりはたべたことある？
- Student: もちろん！はじめはからいものがたべられなかったけど、いまはたべられるようになったよ。
- Agent: すごい！わたしはからいものがにがてで。。。でも、すこしずつたべられるようになりたいな。
- Student: まえはわたしもぜんぜんだめだったんだけど、なれたらだいじょうぶになった。
- Agent: そうなんだ。にほんにきてから、なにかかわったことある？
- Student: うん、あさはやくおきられるようになった。まえはぜんぜんおきられなかったのに。
- Agent: えー、わたしはぎゃくで、にほんにきてからよるおそくまでおきてるようになっちゃって、けんこうてきじゃなくなった。
- Student: それはよくないね。はやくねるようにしたほうがいいよ。
- Agent: うん、わかってるんだけどね。

Roleplay Instructions:
The agent asks the student about life experiences (travel, food, hobbies) and discusses personal changes. The student should naturally use ～たことがある for experiences and ～ようになった for changes. The agent should also introduce ～なくなった (no longer do ~) and ～ようにしている (making an effort to ~). Use show_slide to display a timeline graphic showing "before → change → now" with example sentences illustrating the progression. Use start_timer for a 60-second drill: agent asks "～たことある？" questions and the student answers honestly and quickly, then follows up with a ～ようになった sentence about how they have changed.

Timed Drill (60 seconds):
Agent asks → student answers with experience + change:
ひとりでりょこうしたことある？ → ある。さいしょはこわかったけど、ひとりでもたのしめるようになった。
なっとうをたべたことある？ → ない。でもいつかたべてみたい。
おおぜいのまえではなしたことある？ → ある。まえはきんちょうしてたけど、なれてきたよ。

**Key Concepts:**
- Describe experience with ～たことがある: いったことがある (have been), たべたことがない (have never eaten)

## Section 2: Asking Someone to Do Something — てもらう/てくれる Chains

**Content:**
This section focuses entirely on the giving/receiving-of-favor constructions in practical use: てもらう (get someone to do), てくれる (someone does for me), てあげる (do for someone), and their polite equivalents. These are among the most useful and most difficult N4 grammar points to use naturally.

Model Dialogue:
- Agent: たいへんそうだね。にもつがおおいけど、てつだおうか？
- Student: ほんとに？てつだってくれる？たすかる！
- Agent: このおもいのをもってあげるよ。
- Student: ありがとう。じつは、あしたひっこしなんだけど、ともだちにてつだってもらうよていなんだ。
- Agent: そうなんだ。ほかにだれがくるの？
- Student: たなかくんにくるまをだしてもらえることになったし、すずきさんにはにもつをはこぶのをてつだってもらうつもり。
- Agent: わたしもいこうか？
- Student: え、いいの？きてくれたらすごくたすかるんだけど。。。
- Agent: もちろん！ともだちでしょ。
- Student: ありがとう！あ、それで、ひとつおねがいがあるんだけど。。。ふどうさんやにかぎをかえしにいってもらえないかな？
- Agent: いいよ。なんじまでにかえせばいいの？
- Student: ごごごじまでにかえしてもらえるとたすかるんだけど。
- Agent: りょうかい。まかせて！

Roleplay Instructions:
The agent and student plan a collaborative task (moving, party preparation, group project). The student must make requests using てもらう/てくれる and offer help using てあげる. The agent should set up chains of favors: "たなかくんに～してもらって、そのあとすずきさんに～してもらう" to practice complex request chains. If the student uses only basic おねがい/たのむ forms, the agent should model the てもらう construction and ask them to rephrase. Use open_sketchpad to display the three-way relationship: てあげる (I do for you ↓), てくれる (you do for me ↑), てもらう (I get you to do ←), with polite versions ていただく/てくださる. Run a start_timer 60-second drill: agent describes who does what for whom and the student restates using the correct construction.

Timed Drill (60 seconds):
Situation → student uses correct てもらう/てくれる/てあげる:
たなかくんがわたしのにもつをもった → たなかくんがにもつをもってくれた
わたしがせんせいにてがみをなおしてもらった → せんせいにてがみをなおしてもらった / なおしていただいた

**Key Concepts:**
- Request with てもらう: ～してもらえない？(casual), ～していただけませんか (polite)
- Appreciate with てくれる: てつだってくれてありがとう、きてくれたらたすかる
- Offer with てあげる: もってあげるよ、おしえてあげようか
- Chain requests: ～してもらって、そのあと～してもらう
- Phrases: たすかる (that helps / I'm saved), まかせて (leave it to me), おねがいがあるんだけど (I have a favor to ask), ～ことになった (it's been decided that), ～つもり (intend to), ～てもらえると​たすかるんだけど (it would help if you could ~)

## Section 3: Explaining a Complicated Situation — のに/ので/し

**Content:**
This section practices giving extended explanations using multiple reason-giving and contrast-expressing grammar points: ので (because — polite), から (because — casual), し (listing reasons), のに (despite), けど/のに for contrast. The student explains complex situations that require combining multiple clauses.

Model Dialogue:
- Agent: きのう、なんでパーティーにこなかったの？
- Student: ごめん、いきたかったのに、いけなかったんだ。
- Agent: どうしたの？
- Student: じつは、しごとがおそくなったし、でんしゃもおくれたし、けっきょくいえについたのがじゅういちじだったんだ。
- Agent: じゅういちじ！？それはたいへんだったね。
- Student: うん。しかも、つかれすぎてて、れんらくするのもわすれちゃって。ほんとうにごめん。
- Agent: まあ、しかたないよ。でも、せっかくたなかくんがケーキをつくってくれたのに、たべられなかったのはもったいなかったね。
- Student: えー、たなかくんがケーキつくったの！？しらなかった。。。くやしい。
- Agent: うん。すごくおいしかったよ。しゃしんとっといたからみせてあげる。
- Student: みたいけどみたくない。。。つぎは、しごとがいそがしくても、ぜったいいくようにする。
- Agent: うん、つぎはぜひね！

Roleplay Instructions:
The agent asks the student to explain why something happened — why they missed an event, why they were late, why a plan failed. The student must construct multi-clause explanations using し for listing reasons, のに for "despite," and ので/から for cause. The agent should ask follow-up questions that force the student to add more clauses: "ほかにもりゆうがあったんじゃない？" "でも～だったのに、なんで？" Use show_slide to display a conjunction comparison chart: し (reason listing, casual), ので (polite reason), から (casual reason), のに (despite/although), けど (but/although). Run a start_timer 60-second drill: agent gives two facts and the student connects them with the specified conjunction.

Timed Drill (60 seconds):
Two facts + specified conjunction → student connects:
あめがふった / さんぽにいった (のに) → あめがふったのに、さんぽにいった
やすかった / おいしかった (し) → やすかったし、おいしかったし、いいみせだった
びょうきだった / しごとにいった (のに) → びょうきだったのに、しごとにいった
でんしゃがおくれた / おくれた (ので) → でんしゃがおくれたので、おくれてしまいました

**Key Concepts:**
- List multiple reasons with し: しごとがおそくなったし、でんしゃもおくれたし (work ran late AND the train was delayed)
- Express contrast/regret with のに: いきたかったのにいけなかった (wanted to go but couldn't), つくってくれたのに (even though they made it)
- Give polite reasons with ので: おくれたのでしつれいしました (I was late so excuse me)
- Combine for complex explanations: ～し、～のに、けっきょく～
- Phrases: けっきょく (in the end), しかも (moreover/on top of that), つかれすぎてて (was too tired), れんらくするのをわすれた (forgot to contact), せっかく (with effort/specially), もったいない (wasteful/what a shame), くやしい (frustrating), ぜったい～ようにする (I'll make sure to ~)

## Section 3: Free Conversation with Natural Error Correction

**Content:**
This final section is an open-ended conversation. No set scenario — the student chooses a topic and talks freely for an extended period. The agent's role shifts from teacher to conversation partner who corrects naturally, the way a Japanese friend would: by rephrasing rather than explicitly correcting, or by gently noting errors only when they cause misunderstanding.

Conversation Approach:
The agent should:
1. Let the student lead the conversation topic
2. Respond naturally, as a real conversation partner
3. When the student makes an error, use "recasting" — repeat their sentence correctly without explicitly saying "that's wrong":
   - Student: きのうともだちにあいました。えいがをみるした。
   - Agent: えいがをみたんだ！なんのえいが？ (naturally recasts みるした → みた)
4. Only explicitly correct errors that are persistent or cause confusion:
   - "あ、さっきから気になってたんだけど、～じゃなくて～だよ。"
5. Periodically check in: "ここまでで、なにかわからなかったことはある？"
6. At the end, provide a summary of errors and areas of strength

The agent should use open_sketchpad to note down errors as they occur (visible to the student as a running list) and review them at the end. The agent should also use show_slide at the end to display a "conversation report card" with categories: Register Appropriateness, Vocabulary Range, Grammar Accuracy, Fluency/Natural Flow, and Listening Comprehension.

Topics the agent can suggest if the student cannot choose:
- りょこうのけいかく (travel plans)
- しょうらいのゆめ (future dreams)
- にほんぶんかでおどろいたこと (surprising things about Japanese culture)
- すきなたべものやりょうり (favorite food and cooking)
- さいきんのニュース (recent news)

**Key Concepts:**
- Sustain extended conversation on any topic for 5+ minutes
- Self-correct when noticing own errors: あ、ちがう、～じゃなくて～
- Ask for help naturally: なんていうんだっけ？、～ってにほんごでなんていう？
- Manage conversation flow: topic changes, follow-up questions, showing interest
- Phrases for conversation management: ところで (by the way), そういえば (speaking of which), はなしがかわるけど (changing the subject), なんのはなしだっけ？ (what were we talking about?), もうちょっとくわしくおしえて (tell me more details), それでどうなったの？ (then what happened?)
