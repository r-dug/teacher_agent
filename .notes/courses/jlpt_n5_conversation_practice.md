# JLPT N5 Conversation Practice Course

> **Target:** Spoken fluency at JLPT N5 level
> **Companion to:** JLPT N5 Complete Japanese Course (grammar, writing, kanji)
> **Focus:** Real-world conversational competency through scenario-based practice
> **Lessons:** 8 | **Sections:** 27

# Lesson 1 — First Contact: Greetings, Self-Introduction & Basic Pleasantries

## Section 1: Meeting Someone New

**Content:**
This scenario puts the student in the situation of meeting a Japanese person for the first time at a social gathering. The focus is on natural greeting flow, self-introduction, and basic questions about each other.

Before starting the roleplay, the agent should use **open_sketchpad** to display the key phrases for this scenario as a reference panel (text_bg). Then walk through the model dialogue line by line, having the student repeat each of their lines with correct pronunciation.

**Model Dialogue:**
- Agent (Tanaka): はじめまして。たなかです。
- Student: はじめまして。[student name]です。
- Agent: おくには どちらですか。(Where are you from?)
- Student: [country]から きました。(I came from [country].)
- Agent: そうですか。おしごとは なんですか。(I see. What is your work?)
- Student: がくせいです。/ かいしゃいんです。(I'm a student. / I'm an office worker.)
- Agent: いいですね。にほんごが じょうずですね。(That's nice. Your Japanese is good.)
- Student: いいえ、まだまだです。(No, I still have a long way to go.)
- Agent: どうぞ よろしく おねがいします。(Please treat me well / Nice to meet you.)
- Student: こちらこそ、よろしく おねがいします。(Likewise, nice to meet you.)

After walking through the dialogue, the agent should do a **roleplay round** where the agent plays Tanaka and the student responds naturally without reading. The agent should gently correct pronunciation and phrasing.

Then run a **timed drill** using **start_timer** (90 seconds): the agent asks rapid-fire self-introduction questions in Japanese and the student must answer each within about 10 seconds. Questions: おなまえは? おくには? おしごとは? なんさいですか? しゅみは なんですか?

**Key Concepts:**
- Can introduce oneself naturally: はじめまして。[name]です。どうぞ よろしく おねがいします。
- Can state country of origin: [country]から きました
- Can answer basic personal questions (job, age, hobby): がくせいです / にじゅうさいです / しゅみは [hobby]です
- Can use the humble deflection まだまだです when complimented
- Phrases: はじめまして (nice to meet you — first time), どうぞ よろしく おねがいします (please treat me well), こちらこそ (likewise), おくには どちらですか (where is your country?), おしごとは なんですか (what is your work?), まだまだです (I still have a long way to go), そうですか (I see)

## Section 2: Classroom Introduction

**Content:**
The student has just joined a Japanese language class. The teacher (played by the agent) asks them to stand up and introduce themselves to the class. This scenario practices a slightly more formal self-introduction monologue followed by classmate Q&A.

The agent should first use **open_sketchpad** (text_bg) to show the structure of a Japanese self-introduction:
1. はじめまして (Opening)
2. [name]です (Name)
3. [country]から きました (Origin)
4. [occupation/status] (What you do)
5. しゅみは [hobby]です (Hobby)
6. どうぞ よろしく おねがいします (Closing)

The agent coaches the student to deliver the full introduction as a connected monologue. After the student delivers it, the agent plays various "classmates" asking follow-up questions.

**Model Dialogue:**
- Agent (Teacher): では、じこしょうかいを おねがいします。(Please give your self-introduction.)
- Student: はじめまして。[name]です。[country]から きました。だいがくせいです。しゅみは おんがくです。どうぞ よろしく おねがいします。
- Agent (Classmate Yuki): [name]さん、おんがくが すきですか。どんな おんがくですか。(You like music? What kind?)
- Student: ロックが すきです。(I like rock.)
- Agent (Classmate Ken): にほんごの べんきょうは いつからですか。(Since when have you been studying Japanese?)
- Student: さんかげつまえからです。(Since three months ago.)
- Agent (Teacher): じょうずですね。がんばってください。(That's good. Do your best.)
- Student: ありがとうございます。がんばります。(Thank you. I will do my best.)

After the roleplay, run a **timed drill** with **start_timer** (60 seconds): the student must deliver a complete self-introduction monologue from memory without pausing for more than 3 seconds at any point. The agent evaluates fluency and completeness.

**Key Concepts:**
- Can deliver a structured self-introduction monologue (6 components) smoothly
- Can answer follow-up questions about hobbies and interests: [hobby]が すきです
- Can express duration: [number]かげつまえから (since X months ago)
- Can respond to encouragement: ありがとうございます。がんばります。
- Phrases: じこしょうかいを おねがいします (please introduce yourself), どんな [noun]ですか (what kind of X?), いつからですか (since when?), がんばってください (do your best), がんばります (I will do my best), さんかげつまえから (since three months ago)

## Section 3: Running Into a Neighbor

**Content:**
The student lives in a Japanese apartment building and bumps into a neighbor in the hallway or elevator. This scenario practices casual daily greetings, small talk about weather, and polite parting phrases. The focus is on time-of-day greetings and natural filler phrases.

The agent should use **open_sketchpad** (text_bg) to display the three time-based greetings:
- Morning: おはようございます
- Daytime: こんにちは
- Evening: こんばんは

The agent picks a random time of day for each roleplay round. The student must use the correct greeting.

**Model Dialogue:**
- Agent (Neighbor Suzuki): あ、おはようございます。(Ah, good morning.)
- Student: おはようございます。すずきさん、おでかけですか。(Good morning. Suzuki-san, are you going out?)
- Agent: ええ、ちょっと かいものに。きょうは いい てんきですね。(Yes, just a bit of shopping. Nice weather today, isn't it.)
- Student: そうですね。あたたかいですね。(That's right. It's warm, isn't it.)
- Agent: そうそう。じゃ、いってきます。(Yeah yeah. Well, I'm heading out.)
- Student: いってらっしゃい。(Have a good trip / See you later.)
- Agent: あ、[name]さん、こんど いっしょに おちゃでも どうですか。(Ah, [name]-san, how about tea together sometime?)
- Student: いいですね。ぜひ。(That sounds nice. Definitely.)
- Agent: じゃ、また。(Well, see you.)
- Student: はい、また。(Yes, see you.)

The agent should do **three rapid roleplay rounds** with different times of day and different small talk topics (weather, weekend plans, a package delivery). Use **start_timer** (45 seconds per round) to keep it snappy.

**Key Concepts:**
- Can select the correct time-of-day greeting: おはようございます / こんにちは / こんばんは
- Can make natural small talk about weather: いい てんきですね / あたたかいですね / さむいですね
- Can use the いってきます / いってらっしゃい pair correctly
- Can respond to casual invitations: いいですね。ぜひ。
- Phrases: おでかけですか (are you heading out?), ちょっと かいものに (just a bit of shopping), そうですね (that's right / indeed), そうそう (yeah yeah — casual agreement), いってきます (I'm heading out), いってらっしゃい (safe travels / see you), こんど (sometime/next time), おちゃでも どうですか (how about tea?), ぜひ (definitely/by all means), じゃ、また (well, see you)

# Lesson 2 — Shopping & Money

## Section 1: At the Convenience Store (コンビニ)

**Content:**
The student is buying items at a Japanese convenience store (konbini). This scenario practices basic purchasing interactions including asking for items, understanding the cashier's questions, and paying. Japanese convenience stores are highly scripted — cashiers say predictable phrases, making this excellent listening practice.

The agent should use **open_sketchpad** (text_bg) to display common konbini cashier phrases the student will hear:
- いらっしゃいませ (Welcome)
- ポイントカードは おもちですか (Do you have a point card?)
- おべんとう、あたためますか (Shall I heat the bento?)
- ふくろは いりますか (Do you need a bag?)
- [amount]えんに なります (That will be [amount] yen)

Walk through the model dialogue, then have the student practice responding naturally to each cashier question.

**Model Dialogue:**
- Agent (Cashier): いらっしゃいませ。
- Student: (places items on counter — says nothing, this is normal)
- Agent: ポイントカードは おもちですか。(Do you have a point card?)
- Student: いいえ、もっていません。(No, I don't have one.) / だいじょうぶです。(I'm fine.)
- Agent: おべんとう、あたためますか。(Shall I heat the bento?)
- Student: はい、おねがいします。(Yes, please.)
- Agent: ふくろは いりますか。(Do you need a bag?)
- Student: はい、おねがいします。/ いいえ、だいじょうぶです。
- Agent: ごひゃくにじゅうえんに なります。(That will be 520 yen.)
- Student: すいません、せんえんで おねがいします。(Excuse me, with 1000 yen please.) [hands over money]
- Agent: よんひゃくはちじゅうえんの おかえしです。ありがとうございました。(480 yen is your change. Thank you.)
- Student: ありがとうございます。

After the dialogue walkthrough, run a **timed listening drill** with **start_timer** (120 seconds): the agent rapidly plays the cashier saying different prices and the student must repeat back the amount in Japanese to confirm they understood. Cover numbers: 120, 350, 480, 670, 890, 1050, 1500, 2300. The agent should say each price naturally (ひゃくにじゅうえんになります) and the student repeats just the number.

**Key Concepts:**
- Can navigate a convenience store transaction without confusion
- Can understand and respond to standard cashier questions: ポイントカード, あたためますか, ふくろ
- Can hear and comprehend prices in yen up to several thousand
- Can specify payment: [amount]で おねがいします
- Phrases: いらっしゃいませ (welcome — no response needed), ポイントカードは おもちですか (do you have a point card?), あたためますか (shall I heat it?), ふくろは いりますか (do you need a bag?), [amount]えんに なります (that will be X yen), おかえし (change), だいじょうぶです (I'm fine / no thanks), おねがいします (please)

## Section 2: At a Clothing Shop

**Content:**
The student is shopping for clothes and needs to ask about sizes, colors, try things on, and make a decision. This scenario practices demonstrative pronouns (これ/それ/あれ), color vocabulary, and polite requests.

The agent should use **show_slide** to display an image of a clothing shop or use **open_sketchpad** (text_bg) to show a layout of items with labels:
- Tシャツ (T-shirt) — しろ (white), くろ (black), あか (red), あお (blue)
- Sizes: S, M, L

Walk through the dialogue, emphasizing the pointing words (これ/それ/あれ) and how to ask to try something on.

**Model Dialogue:**
- Agent (Shop staff): いらっしゃいませ。なにか おさがしですか。(Welcome. Are you looking for something?)
- Student: Tシャツを さがしています。(I'm looking for a T-shirt.)
- Agent: こちらに ございます。どんな いろが いいですか。(They're over here. What color would you like?)
- Student: あおいのは ありますか。(Do you have a blue one?)
- Agent: はい、こちらです。サイズは いかがですか。(Yes, here. What size?)
- Student: Mサイズは ありますか。(Do you have size M?)
- Agent: はい、ございます。しちゃくしますか。(Yes, we do. Would you like to try it on?)
- Student: はい、おねがいします。(Yes, please.)
- [After trying on]
- Agent: いかがですか。(How is it?)
- Student: ちょっと おおきいです。Sサイズは ありますか。(It's a little big. Do you have size S?)
- Agent: はい、どうぞ。(Yes, here you go.)
- Student: これに します。いくらですか。(I'll take this one. How much is it?)
- Agent: にせんえんです。(2000 yen.)

After the roleplay, do a **timed drill** using **start_timer** (90 seconds): the agent describes items (color + item + size) and the student must request them politely. For example: "Ask for a red T-shirt in size L" — student says あかい Tシャツの Lサイズは ありますか。

**Key Concepts:**
- Can ask if an item is available: [item]は ありますか
- Can specify color preferences: あおいのは ありますか / あかいのが いいです
- Can ask to try on clothing: しちゃくしてもいいですか
- Can express fit issues: ちょっと おおきいです / ちょっと ちいさいです
- Can make a purchase decision: これに します (I'll take this one)
- Phrases: なにか おさがしですか (are you looking for something?), さがしています (I'm looking for...), いかがですか (how is it?), しちゃく (trying on clothes), これにします (I'll take this), いくらですか (how much is it?), ちょっと おおきい/ちいさい (a little big/small), ございます (polite: we have it)
- Colors: しろ/しろい (white), くろ/くろい (black), あか/あかい (red), あお/あおい (blue), きいろ/きいろい (yellow), みどり (green)

## Section 3: At a Market — Asking Prices

**Content:**
The student is at an open market or street stall in Japan, asking about prices and quantities. This scenario practices counter words for items, negotiation-light phrases, and deciding between options.

The agent should use **open_sketchpad** (text_bg) to display common counter words:
- ～こ (small round things: apples, oranges)
- ～ほん/ぽん/ぼん (long thin things: bottles, bananas)
- ～まい (flat things: plates, tickets)
- ～つ (general counter: ひとつ, ふたつ, みっつ...)

Walk through the dialogue, then drill counters.

**Model Dialogue:**
- Agent (Vendor): いらっしゃい！きょうは りんごが やすいよ！(Welcome! Apples are cheap today!)
- Student: りんごは いくらですか。(How much are the apples?)
- Agent: ひとつ ひゃくえん。みっつで にひゃくえん。(100 yen each. Three for 200 yen.)
- Student: じゃ、みっつ ください。(Then, three please.)
- Agent: はい！ほかには？(Sure! Anything else?)
- Student: あの みかんも ください。いつつ おねがいします。(Those mandarin oranges too please. Five please.)
- Agent: みかんは いつつで さんびゃくえん。ぜんぶで ごひゃくえんね。(Oranges are five for 300 yen. 500 yen total.)
- Student: はい。せんえんで おねがいします。(Yes. With 1000 yen please.)
- Agent: ごひゃくえんの おつりね。まいど！(500 yen change. Thanks for your business!)
- Student: ありがとうございます。

After the dialogue, run a **timed counter drill** with **start_timer** (120 seconds): the agent names an item and a number, and the student must say the correct counter phrase. Examples: "3 apples" → りんご みっつ / りんご さんこ, "2 bottles" → にほん, "4 sheets of paper" → よんまい, "1 banana" → いっぽん. Rotate through 12-15 items rapidly.

**Key Concepts:**
- Can ask prices and understand the response: [item]は いくらですか
- Can use the general counter ～つ: ひとつ, ふたつ, みっつ, よっつ, いつつ, むっつ, ななつ, やっつ, ここのつ, とお
- Can use specific counters: ～こ, ～ほん/ぽん/ぼん, ～まい
- Can order quantities: [number + counter] ください
- Can understand totals: ぜんぶで [amount]えん
- Phrases: いくらですか (how much?), ～ください (please give me), ほかには (anything else?), ぜんぶで (in total), おつり (change), まいど (thanks for your patronage — casual), やすい (cheap), たかい (expensive), じゃ (well then)

# Lesson 3 — Food & Dining

## Section 1: Ordering at a Restaurant

**Content:**
The student enters a restaurant, gets seated, orders food and drinks, and interacts with the waiter. This is one of the most practical N5 conversation scenarios. Japanese restaurant interactions follow a predictable pattern that students can master quickly.

The agent should use **open_sketchpad** (text_bg) to display a simple menu:
- ラーメン (ramen) — 800えん
- カレーライス (curry rice) — 750えん
- やきざかな ていしょく (grilled fish set meal) — 900えん
- ビール (beer) — 500えん
- おちゃ (tea) — むりょう (free)
- みず (water) — むりょう

Then walk through the full restaurant flow from entering to ordering.

**Model Dialogue:**
- Agent (Staff at door): いらっしゃいませ。なんめいさまですか。(Welcome. How many people?)
- Student: ふたりです。(Two people.)
- Agent: おたばこは すいますか。(Do you smoke?) [Note: less common now but still appears in N5]
- Student: すいません。(No, we don't.)
- Agent: こちらへ どうぞ。メニューです。(This way please. Here's the menu.)
- [Time passes]
- Agent (Waiter): ごちゅうもんは おきまりですか。(Have you decided on your order?)
- Student: はい。ラーメンを ひとつと、カレーライスを ひとつ おねがいします。(Yes. One ramen and one curry rice, please.)
- Agent: おのみものは いかがですか。(How about drinks?)
- Student: ビールを ひとつと、おちゃを おねがいします。(One beer and tea, please.)
- Agent: かしこまりました。しょうしょう おまちください。(Certainly. Please wait a moment.)
- [Food arrives]
- Agent: おまたせしました。ラーメンと カレーライスです。(Sorry for the wait. Ramen and curry rice.)
- Student: ありがとうございます。いただきます。(Thank you. I'll eat now. [lit: I humbly receive])

The agent should run this roleplay multiple times with the student ordering different combinations from the menu. Use **start_timer** (60 seconds) for a speed round where the student must order three different complete meals (food + drink) as fast as possible.

**Key Concepts:**
- Can state party size: ひとりです / ふたりです / さんにんです
- Can order food and drinks: [item]を [counter] おねがいします
- Can understand standard waiter phrases: ごちゅうもんは? おのみものは?
- Can say いただきます before eating and ごちそうさまでした after
- Phrases: なんめいさまですか (how many people?), ごちゅうもんは おきまりですか (have you decided?), おのみものは いかがですか (how about drinks?), かしこまりました (certainly — formal), しょうしょう おまちください (please wait a moment), おまたせしました (sorry for the wait), いただきます (before eating), ごちそうさまでした (after eating)

## Section 2: Casual Dining — At an Izakaya

**Content:**
The student is at an izakaya (casual Japanese pub) with friends. The language here is more casual than a formal restaurant. This scenario practices casual speech, group ordering, and common izakaya vocabulary.

The agent should use **open_sketchpad** (text_bg) to display an izakaya-style menu:
- えだまめ (edamame) — 300えん
- からあげ (fried chicken) — 500えん
- やきとり (grilled chicken skewers) — 400えん (5ほん)
- たこわさ (octopus with wasabi) — 350えん
- なまビール (draft beer) — 450えん
- ハイボール (highball) — 400えん
- ウーロンちゃ (oolong tea) — 250えん

This scenario is more casual. The agent plays a friend and also the waiter at different points.

**Model Dialogue:**
- Agent (Friend Kenji): とりあえず、ビールにする？(First off, shall we go with beer?)
- Student: うん、ビールで。(Yeah, beer for me.)
- Agent (Friend): すみませーん！(Excuse me! [calling waiter])
- Agent (Waiter): はい、おきまりですか。
- Agent (Friend): なまビール ふたつと、えだまめと、からあげ おねがいします。
- Agent (Friend to student): ほかに なにか たべたい？(Anything else you wanna eat?)
- Student: やきとりが たべたいです。(I want to eat yakitori.)
- Agent (Friend): いいね。すみません、やきとりも おねがいします。
- Agent (Waiter): かしこまりました。
- [Drinks arrive]
- Agent (Friend): じゃ、かんぱーい！(Cheers!)
- Student: かんぱい！
- Agent (Friend): つぎ、なに のむ？(Next, what'll you drink?)
- Student: ハイボールに します。(I'll have a highball.)

After the roleplay, the agent should highlight the differences between formal and casual ordering. Then run a **switching drill** with **start_timer** (90 seconds): the agent gives a situation (formal restaurant vs. izakaya) and an item, and the student must order it in the appropriate register. Example: "Formal, two beers" → ビールを ふたつ おねがいします。"Casual, two beers" → なま ふたつで。

**Key Concepts:**
- Can order casually in a group setting: [item]で / [item]に する
- Can express food preferences: [food]が たべたいです / [drink]が のみたいです
- Can participate in group ordering and toasting: かんぱい
- Can switch between formal and casual register when ordering
- Phrases: とりあえず (first off / for starters), すみませーん (excuse me — calling staff, drawn out), なにか たべたい？(wanna eat something?), いいね (sounds good — casual), かんぱい (cheers), つぎ なに のむ？(what'll you drink next?), [item]にする (I'll go with X — casual), [item]で (X for me — very casual)

## Section 3: Asking About Ingredients & Allergies

**Content:**
The student has a food allergy or dietary restriction and needs to communicate this at a restaurant. This is a critical real-life scenario. The agent should emphasize that getting this right matters for safety.

The agent should use **open_sketchpad** (text_bg) to display key allergy/dietary vocabulary:
- アレルギー (allergy)
- たまご (egg)
- にゅうせいひん / ぎゅうにゅう (dairy / milk)
- こむぎ (wheat)
- ピーナッツ (peanuts)
- えび (shrimp)
- にく (meat)
- ベジタリアン (vegetarian)
- はいっていますか (is it included?)

**Model Dialogue:**
- Student: すみません、ちょっと きいてもいいですか。(Excuse me, may I ask something?)
- Agent (Waiter): はい、どうぞ。(Yes, go ahead.)
- Student: わたしは たまごの アレルギーが あります。この りょうりに たまごは はいっていますか。(I have an egg allergy. Does this dish contain egg?)
- Agent: そうですね、ちょっと かくにんします。しょうしょう おまちください。(Let me check. Please wait a moment.)
- Agent: もうしわけありません、こちらの りょうりには たまごが はいっています。(I'm sorry, this dish contains egg.)
- Student: そうですか。じゃ、たまごなしで できますか。(I see. Can you make it without egg?)
- Agent: はい、だいじょうぶです。たまごぬきで おつくりします。(Yes, that's fine. We'll make it without egg.)
- Student: ありがとうございます。じゃ、それを おねがいします。(Thank you. Then, that one please.)
- Agent: かしこまりました。ほかに アレルギーは ございますか。(Certainly. Are there any other allergies?)
- Student: いいえ、たまごだけです。(No, just egg.)

After the dialogue, the agent should drill different allergy scenarios. Use **start_timer** (120 seconds) for a drill where the agent names a dish and an allergen, and the student must ask about it and request a modification. Cycle through: えびアレルギー + ラーメン, にくなし + カレー, ぎゅうにゅう + ケーキ, ピーナッツ + サラダ.

**Key Concepts:**
- Can clearly state a food allergy: [food]の アレルギーが あります
- Can ask if an ingredient is in a dish: [ingredient]は はいっていますか
- Can request a modification: [ingredient]なしで できますか
- Can understand the response (yes it contains / no it doesn't): はいっています / はいっていません
- Phrases: きいてもいいですか (may I ask?), アレルギーが あります (I have an allergy), はいっていますか (is it included/contained?), ～なしで できますか (can you make it without X?), ～ぬき (without — e.g., たまごぬき), かくにんします (I'll check), もうしわけありません (I'm sorry — formal), だいじょうぶです (it's okay / that's fine)

## Section 4: Paying the Bill

**Content:**
The student has finished eating and needs to pay. This scenario covers getting the check, asking about payment methods, splitting the bill, and the exchange at the register. In Japan, you typically pay at the register near the exit, not at the table.

The agent should briefly explain the cultural context: in Japan you usually bring the bill slip (でんぴょう) to the register. Splitting the bill (わりかん) is common among friends. Tipping does not exist.

**Model Dialogue:**
- Student: すみません、おかいけいを おねがいします。(Excuse me, the check please.)

## Section 4: Phone Call Basics

- Agent (Restaurant): はい、さくらレストランです。(Yes, Sakura Restaurant.)
- Student: もしもし、すみません。よやくを したいんですが。(Hello, excuse me. I'd like to make a reservation.)

- Student: こんどの きんようびの よるは あいていますか。(Is next Friday evening available?)
- Agent: きんようびですね。なんめいさまですか。(Friday, right. How many people?)
- Student: よにんです。(Four people.)
- Agent: おじかんは？(What time?)
- Student: しちじは だいじょうぶですか。(Is 7 o'clock okay?)
- Agent: はい、だいじょうぶです。おなまえを おねがいします。(Yes, that's fine. Your name please.)
- Student: [name]です。(It's [name].)
- Agent: [name]さまですね。きんようび しちじ よんめいさまで おとりしました。(Mr/Ms [name]. Booked for Friday at 7, party of four.)

**Key Concepts:**
- Can initiate a phone call appropriately with もしもし
- Can make a restaurant reservation by phone: よやくを したいんですが
- Can specify date, time, and party size for a reservation

14. もういちど おねがいします → (repeats previous statement)
15. おだいじに → ありがとうございます

**Round 3 — Situational Sprint (90 seconds):**
The agent describes a situation in 5 words or fewer and the student must produce the most natural phrase:
1. "Enter a shop" → (silence — customer doesn't respond to いらっしゃいませ)

**Key Concepts:**
- Can produce common phrases automatically without translation delay
- Can respond appropriately to standard Japanese conversational prompts

- Demonstrates automaticity across all N5 conversational domains

## Section 3: Free Conversation with Correction

**Content:**
This final section is an open-ended free conversation. The agent and student simply talk — about anything the student wants. The agent adjusts to the student's level, gently pushing them to use new vocabulary and structures while keeping the conversation flowing naturally.

The agent should begin by asking the student what they want to talk about. If the student has no preference, the agent should suggest one of these topics:
- Travel plans / places you want to visit in Japan
- Hobbies and free time activities
- Your family and friends
- Food you like and want to try
- Your experience learning Japanese

**Guidelines for the agent during free conversation:**
1. Speak at natural N5 speed — not too slow, not too fast
2. Use only N5-level vocabulary and grammar (with occasional N4 words explained in context)
3. When the student makes an error, DO NOT interrupt — note it and correct at natural pause points
4. Use recasting: repeat what the student said but correctly, naturally
5. Ask follow-up questions to keep the conversation going
6. Every 3-4 minutes, use **open_sketchpad** (text_bg) to display new vocabulary that came up in the conversation
7. Encourage the student to ask questions back — conversation is two-directional
8. If the student gets stuck, offer a hint rather than giving the answer

**Correction approach:**
- For pronunciation: model the correct version naturally
- For grammar: recast the sentence correctly
- For vocabulary: give the word they're looking for with context
- At the end: use **open_sketchpad** (text_bg) to display a summary of corrections and new vocabulary learned

The agent should run this conversation for as long as the student is engaged, aiming for at least 10 minutes of sustained conversation. Use **start_timer** (600 seconds) as a soft benchmark — when the timer ends, the agent can suggest wrapping up or continuing.

At the end of the conversation, the agent should provide:
1. Overall assessment of conversational ability
2. Top 3 strengths observed
3. Top 3 areas for improvement
4. Specific phrases or patterns to practice before the next session

Display this feedback using **open_sketchpad** (text_bg).

**Key Concepts:**
- Can sustain a free-form conversation on familiar topics for 10+ minutes
- Can self-correct when errors are pointed out
- Can ask questions and show interest in the conversation partner
- Can use filler words naturally: えーと (umm), あのう (well), そうですね (let me think)
- Can handle moments of not knowing a word: ～は にほんごで なんですか (what is X in Japanese?)
- Conversation fillers and connectors: えーと (umm), あのう (well/umm), そうですね (let me see), なるほど (I see / makes sense), へえ (oh really?), それで (and then), ところで (by the way), じつは (actually)
